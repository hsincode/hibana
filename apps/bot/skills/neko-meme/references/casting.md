# 素材の選び方 (キャスティング)

台本ができたら、次にやるのは「どの猫を、どの背景の、どのサイズで置くか」。
ここを外すと、素材は揃っているのに素人動画になる。

## 1. まず使わない素材を決める

全 93 本を平等に扱わない。**テーマに合わないものと、合成品質が出ないものを
先に落とす**。落とす理由は 3 種類しかない。

| 理由 | 該当素材 | 説明 |
|------|----------|------|
| 背景が抜けない | `teemo`, `teemo-hit` | LoL のゲーム映像。グリーンバックではないので背景合成に使えない |
| 途中でグリーンが終わる | `yt-goat-talking`, `yt-monkey-cart`, `yt-demanding-monkey` | 元動画の尻にタイトルカードが焼き込まれている。`index.json` の `keyed_range` に有効区間が入っているので、`start` と `duration` をその中に収める (外れると `--check` が警告する) |
| 元素材にゴミが入る | `laughing-pointing-cat` | 画面下半分にグレーの板が入っており、暗い背景に貼ると四角い継ぎ目が見える。同じ「煽り」なら `yt-laughing-dog` のほうが綺麗に抜ける |
| 縮小すると読めない | `chipi-chipi`, `yt-chipi-chipi` | ブレの強い顔アップ。画面の 1/3 以下にすると黒い塊にしか見えない。全身が映る `hodomoe-cat` / `dancing-girlfriend` のほうが小さくしても伝わる |

さらに**テーマから外れるもの**を落とす。「ブラック企業の一日」なら
`gojo-cat` (五条悟コスプレ)、`kitten-butt` (子猫のお尻)、`cat-person` /
`goat-person` (人間コスプレ) は文脈が合わないので不採用。

**同系統の重複も 1 本に絞る**。ダンス系だけで `yt-maxwell` / `yt-dj-cat` /
`yt-head-bob-cat` / `yt-spinning-cat` / `yt-dancing-dog` 系 / `chipi-chipi` /
`hodomoe-cat` … と 10 本以上あるが、1 本の動画で 2〜3 本以上使うと
「同じネタの使い回し」に見える。

**猫以外も遠慮なく使う**。配布元には犬・ヤギ・羊・猿が含まれている。
サンプルでは上司役を一貫してヤギ (`yt-goat-talking` / `yt-goat-and-huh`) に
していて、「話が通じない相手」というキャラ付けが画だけで伝わる。

**組み合わせ素材 (1 本に 2 匹以上) は 1 カットで関係を描ける**ので優先度が高い。
`yt-talking-and-huh` (しゃべる猫 + 無知な猫)、`yt-goat-and-huh` (ヤギ + 無知な猫)、
`yt-dog-and-zoning-cat` (笑う犬 + ゾーンアウト黒猫)、`yt-two-cats-face`、
`yt-cat-and-dog` など。1 匹素材を 2 回切り返すより短く、テンポが出る。

### 候補は既定で効く。台本に書けば上書きもできる

採用対象は `assets/catalog.json` の `recommended` フラグで管理していて、
**台本に何も書かなくても既定の候補として効く**。`nm-fetch.py list` /
`nm-bg.py list` も既定でこの候補だけを表示する。候補外を使うと
`nm-build.py --check` が失敗し、ビルド時にも警告が出る。

作品ごとにさらに絞りたいときは、台本のトップレベルに `allowed_materials:` /
`allowed_backgrounds:` として ID を列挙する。

```yaml
allowed_materials:
  - yt-maxwell
  - yt-popcat
  # ...
```

**同じ和名で別動画がある素材があるので、必ず ID で列挙する。**
「眠そうな猫」は `yt-sleepy-cat` / `yt-sleepy-cat-2` / `yt-sleepy-cat-3` の 3 本、
「眠っている猫」は `yt-sleeping-cat` / `-2` の 2 本ある。和名で確認していると
候補外の素材が紛れ込んでも気付けない。

候補そのものを増減させたいときは `assets/catalog.json` / `assets/bg-catalog.json`
の `recommended` を編集する。

`nm-build.py <台本> --check` は使用素材の種類数と、候補のうち使わなかったものも
出すので、意図どおりに絞れているかを一覧で確認できる。

## 2. 素材の「意味」で配役する

見た目ではなく、その素材が観客の中で持っている意味で選ぶ。
**「猫が映っていればいい」で置くと、テロップと画が噛み合わずに違和感が出る。**

判断を外しやすい 3 パターン:

- **2 匹以上の素材は「なぜ 2 匹いるか」が説明できる場面だけ**。深夜のホームで
  一人取り残される画に犬入りの素材を置くと「この犬は誰？」になる。孤独を出す
  カットは必ず 1 匹素材にする。
- **動作の見た目ではなく比喩で読み替える**。`yt-cat-hits-cat` を「無理です」に
  当てると上司を殴っているように見えるが、「大量の仕事を雑にバシバシ捌く」に
  当てると洒落た比喩として機能する。同じ素材でもテロップ次第で意味が変わる。
- **表情の細かい違いを取り違えない**。`yt-big-eyes-cat` は「目が覚めた」ではなく
  **「状況が飲み込めていない」**。`yt-zoning-out` (2 匹が横を向く) は単なる放心では
  なく**「説教されて逆に呆れている」**。ここを外すと画だけ浮く。

検証済みの配役 (そのまま流用してよい):

| テロップ | 素材 | なぜ効くか |
|----------|------|-----------|
| 同僚が運ばれた | `yt-big-eyes-cat` | 目を見開いたまま固まる = 状況が飲み込めていない |
| はい (上司に仕事を追加された直後) | `yt-zoning-out` | 2 匹が横を向いて固まる = 説教されて逆に呆れている |
| 考えるのをやめて数で押す | `yt-cat-hits-cat` | 連打を「殴る」ではなく「捌く」と読み替える |
| 帰宅 | `yt-wet-cat` | 濡れた無表情 = 帰り着いた瞬間の「無」 |

| 素材 | 意味 | 使いどころの例 |
|------|------|----------------|
| `yt-maxwell` | 猫ミームの代名詞 | 冒頭。何の動画か 1 カットで伝わる |
| `yt-talking-and-huh` | しゃべる猫 + 無知な猫 | 上司とのやりとり。1 匹素材を 2 回切り返すより 1 カットで済む |
| `yt-goat-talking` / `yt-goat-and-huh` | 悪気なく喋るヤギ | 話が通じない上司役。同じ動物で統一すると同一人物に見える |
| `yt-cat-huh` | 「え？」 | 想定外の一言を食らった瞬間 |
| `yt-popcat` | 「は？」の口 | 驚き・ショック |
| `yt-big-eyes-cat` | 目を見開く | 周りの状況が飲み込めていないとき |
| `yt-angry-cat` | 怒り | 障害発生・理不尽 |
| `yt-screaming-cat` | 絶叫 | 限界。他のカットより短く切る |
| `yt-cat-hits-cat` | 猫が猫を連打する | **仕事を雑に捌く**。ツッコミに使うと「上司を殴っている」ように見えるので注意 |
| `yt-know-nothing` | とぼける | 「誰も帰らない」など、状況を認めたくないとき |
| `yt-zoning-out` | 2 匹が横を向いて固まる | 説教されて逆に呆れている。1 匹分の孤独には使えない |
| `yt-sleepy-cat` / `yt-sleeping-cat` | 疲弊・就寝 | 一日の始まりと終わり |
| `yt-wet-cat` | 絶望・無 | オチの直前に落とす。1 匹なので孤独の画にも使える |
| `yt-nostalgic-cat` | 遠い目 | 諦めきった通勤、しんみりした回想 |
| `yt-sleepy-cat-3` | 目を閉じたまま抱えられる | まだ寝ていたい朝 |
| `yt-typing-cat` | PC 作業 | 仕事のカット。再登場させて「まだ終わらない」を出せる |
| `yt-nail-file-cat` | 爪やすりで余裕 | 始業前・サボり |
| `yt-crunchy-cat` | カリカリ食べる | 食事シーン。デスクで済ませる昼メシに転用できる |
| `yt-laughing-dog` | 煽り笑い | オチ |
| `yt-dog-and-zoning-cat` | 呆然の横で誰かが笑う | 「笑っている側が誰か」が文脈で分かるときだけ |
| `yt-dj-cat` | 明るく踊る | 〆だけトーンを上げたいとき |
| `pause-button` | 一時停止エフェクト | 猫ではなく演出。ツッコミの間に挟む |

**同じ素材を意図的に再登場させる**のは有効。サンプルでは `yt-typing-cat` を
「9:30 とりあえず手を動かす」と「22:00 まだ半分」の 2 箇所に置いて、
同じ作業を延々やらされていることを画で示している。

## 3. 背景で時間と感情を語らせる

みんちりえの素材は同じ場所の **日中 / 夕方 / 夜・照明ON / 夜・照明OFF** が
揃っているものが多い。これを時系列どおりに並べるだけで、テロップに時刻を
書かなくても「終わらない一日」が伝わる。

```
mc-medium_office-1 (日中) → -2 (夕方) → -3 (夜・照明ON) → -4 (夜・照明OFF)
```

同じ場所の照明違いを 2 カット続けるのも効く。サンプルでは
`mc-machine_room-1` (照明ON) →「サーバが落ちた」、`mc-machine_room-2` (照明OFF)
→「復旧要員、俺一人」と繋いで、状況が悪化したことを画だけで見せている。

`nm-bg.py list --source minchi --variants --only mc-medium_office` で
バリエーションの中身を確認できる。

感情のカット (ツッコミ・絶叫・オチ) も**みんちりえの場所背景のまま**尺だけ
短くする。生成背景 (`focus` 等) は使わない。

### 場所は行動と一致させる

自席で仕事を捌いているカットに応接室 (`mc-office-1`) を当てると、画とテロップが
噛み合わない。同じ「オフィス」でも用途が違う背景があるので、
**そのカットで何をしているか**で選ぶ。サンプルでは 17:30 以降の作業カットを
すべて `mc-medium_office-2` (夕方のオフィス) に揃えて、席から動いていないことを
示している。

### 明るい背景 = テロップにボックスが要る

実写風イラストの上に白抜き文字を置くと、明るい部屋の背景で完全に読めなくなる。
写真・イラスト背景を使うときは `text_style: {box: true}` を必ず入れる。

## 4. 素材の有効区間を確認する

一部の素材は元動画の頭や尻にタイトルカード (黒地に "origin" など) が焼き込まれて
いる。`yt-goat-talking` は 25.9 秒のうちグリーンなのは頭の 8.5 秒だけで、
`start: 4.0` + 5 秒の指定がカードに突っ込んで、完成動画に黒画面と "origin" の
文字がそのまま出た。

`nm-fetch.py index` が `keyed_range` として有効区間を記録しているので、
`nm-build.py <台本> --check` を通せば逸脱を警告してくれる。レンダリング時は
自動で `start` を区間内に寄せるが、必ず警告が出るので黙って直ることはない。

## 5. 切断面は画面の端に隠す

猫ミーム素材の多くは被写体が元動画の端で切れている (足やお尻がフレーム外)。
画面の真ん中に浮かせると平らな切断面が丸見えになる。台本のトップレベルに
`pos: bottom-flush` を入れて画面の下端にぴったり付けると、「床に座っている」
ように見えて破綻しない。

さらに `yt-dj-cat` のように**元素材が矩形に切り抜かれている**ものもある
(左と下が直線)。これはグリーンバックではないので抜きようがないため、
`pos: bottom-left-flush` で画面の左下隅に寄せ、切断面を画面の縁と重ねて消す。

どの素材が下端で切れているかは `index.json` の `subject` (被写体の外接矩形) の
`y + h` が元動画の高さに達しているかで判別できる。

## 6. サイズは `crop: auto` で揃える

素材によってフレーム内で被写体が占める割合が全く違う (`pot-dog` は犬が 1/3、
`waving-cat` は猫が 2/3)。同じ `scale` を書いても仕上がりの大きさが揃わない。

台本のトップレベルに `crop: auto` を入れると、`nm-fetch.py index` が検出した
被写体の外接矩形まで詰めてから拡縮するので、`scale` が素直に
「画面に対する猫の大きさ」として効く。

`scale` は「画面幅に対する猫の幅」だが、`max_height` (既定 0.82) の箱にも
収まるよう縮むので、横長の画で縦にはみ出すことはない。

`crop: auto` 前提の目安 — **16:9 (1920x1080)**:

| 状況 | scale |
|------|-------|
| 2 匹入りの横長素材 (`yt-talking-and-huh`, `yt-goat-and-huh`) | 0.52〜0.56 |
| 顔アップ・横長寄りの単体 (`yt-typing-cat`, `yt-big-eyes-cat`) | 0.36〜0.42 |
| 縦長の単体 (`yt-sleeping-cat`, `yt-angry-cat`, `yt-know-nothing`) | 0.23〜0.28 |
| 被写体検出が効かない素材 (`yt-goat-talking`) | 0.7 前後 (全画面基準になる) |

**縦 (1080x1920)** なら上記の値をおおむね 2 倍にする。

背景素材を使う意味を出すには、**猫を大きくしすぎない**。16:9 では猫の高さが
画面の 6 割程度に収まると、背景の情報量と両立する。

## 7. 背景は静止画のままでよい

猫ミームは猫の動きが主役で、背景はあくまで舞台。背景を動かすと視線が散る。
`bg_zoom` は既定で無効なので、そのままにしておく。

動かしたい場合だけ `bg_zoom: in` / `out` を足す (数 % のゆるいズーム)。

## 8. 素材の音の回数に尺を合わせる

猫ミーム素材は同じ鳴き声を数回繰り返すものが多い。1 回目で切ると「言いかけて
終わった」ように聞こえる。`yt-cat-huh` は「え？」が **0.6s / 4.2s / 7.9s** の
3 回鳴るので、4 秒だと 1 回しか入らない。5 秒取ると 2 回入って間が成立する。

発話の位置は silencedetect で調べられる:

```bash
ffmpeg -i ~/.cache/neko-meme/materials/yt-cat-huh.mp4 \
  -af "silencedetect=noise=-32dB:d=0.2" -f null - 2>&1 | grep silence_
```

## 9. 尺のリズム

16:9 の通常動画は、猫の動き 1 サイクルが見える長さを取る。素材は 5〜15 秒
あるので、4〜5 秒使っても足りなくなることはまずない。

| パート | 秒数 (16:9) |
|--------|-------------|
| つかみ (タイトル) | 4.5 |
| 状況説明 | 4.5〜5.0 |
| セリフ (上司の無茶ぶりなど) | 5.0〜5.5 |
| ツッコミ・絶叫 | 4.0 |
| オチ | 5.0 |
| 締め | 5.0 |

**ツッコミは相対的に短く**。他より 1 秒短いだけでテンポが立つ。

縦型 Shorts にする場合 (`size: shorts`) は 60 秒制限があるので、
各カットを 2〜3 秒に詰めて 57〜58 秒に収める。
`nm-build.py <台本> --check` で合計尺を確認できる。
