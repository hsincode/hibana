# アイコンと OGP 画像の元

`public/` の PNG は、ここにある元から書き出したもの（判断記録: #142）。手で描いた画像は無い。

| 元         | 書き出す先                                                                 | 中身                                                                                      |
| ---------- | -------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `icon.svg` | `public/icon-512.png`（512×512）・`public/apple-touch-icon.png`（180×180） | 端まで塗った墨の地に、`public/favicon.svg` と同じ星                                       |
| `og.html`  | `public/og.png`（1200×630）                                                | 名前・説明と、ログイン画面の図版（`src/Login.tsx`）と同じ同心円・目盛り・放射線・琥珀の星 |

## 書き出し方

```sh
cd apps/web
bun brand/render.ts
```

Playwright の Chromium（画面テストと同じもの）で元を開き、スクリーンショットを書き出す。欧文は同梱の Outfit（`src/fonts/`）、日本語は端末の書体で描かれる。

## 書き出した環境

2026-10-31。Chromium 153.0.8010.12（`@playwright/test` 1.63.0）、日本語は Noto Sans CJK JP（`/usr/share/fonts/noto/NotoSansCJK-Regular.ttc`）。同じ環境で 2 回書き出して、`og.png` が同じバイト列になることを確かめた。別の環境では日本語の書体が変わり、バイト列も変わり得る。
