# ADR-0009: ハーネスをプロバイダーで分け、Anthropic 公式 API だけを Claude 向けにする

- 状態: 提案
- 決定日・判断者: 構成と対象は 2026-10-11、持ち主（#66）。出し方と、切り替え時の履歴の扱いは未定
- 判断の過程を残した Issue: #66（構成・対象・出し方の比較と、本人の判断）、#69（前後の比較の計測）
- 置き換える／置き換えられた ADR: なし

## 要求と決定
- プロダクトの特性と、満たす要求:
  - bot のハーネス（システムプロンプト、モデルに見せるツール、ループ、会話の表現）は Codex CLI を参考に作られ、全プロバイダーで同じものを使っている。Anthropic のターンにも、Codex 向けのプロンプト（`apps/bot/prompts/harness/codex.md`）とツール（`shell_command`、`apply_patch` など）を送っている（#66 の「判断時点の事実」）
  - 要求は 3 つ。Anthropic のモデルに合ったハーネスにすること。Anthropic 以外のプロバイダーに送るリクエストを変えないこと（#67）。新旧を同じビルドで比べられ、bot だけで切り戻せること（#69、ADR-0006）
- 採用する構成・方式（「未定」と書いた点は、#66 で本人が決める。それまでは AI の提案）:
  - ハーネスを 2 つ持つ。`codex`（現行。凍結する）と `claude`（新しく作る）
  - `claude` の対象は `provider === "anthropic"` のターンだけ。`claude_max` と `claude_kiro` を含むほかのプロバイダーは `codex` のまま（確定）
  - `claude` の中身の方針（確定）: Messages API のまま、公式 SDK・Anthropic ネイティブの会話表現・Claude Code 形のツール面・Claude 向けのプロンプトに作り替える。Claude Agent SDK は使わない。プロンプトの本文は Claude Code から写さず、公開ドキュメントを出所として自作し、出所を `docs/harness.md` に記録する
  - 出し方（未定）: bot の環境変数 `ANTHROPIC_HARNESS`（既定 `codex`）と、先に有効にする guild を並べる `ANTHROPIC_HARNESS_GUILDS` で選ぶ。API・DB・契約（`apps/api/src/contract.json`）には項目を足さない
  - 切り替え時の履歴（未定）: 履歴のキーに、`claude` のときだけハーネスの識別子を足す。`codex` のキーは今のまま 1 バイトも変えない。checkpoint にはハーネスの識別子を足し、食い違えば再開しない
  - 配信の順序（未定）: ハーネスの識別子を読める版を先に配信し、識別子を書く版を後に配信する。配信に失敗すると relay が bot を 1 つ前の commit に戻すので（ADR-0006）、戻った先が識別子を読める版であるようにするため
- 比較した代替案と、採用しなかった理由（#66 の比較表。理由の整理は AI によるもので、持ち主の言葉での理由は聞いていない）:
  - Claude Agent SDK を組み込む: 文字どおりの再現になる唯一の案。1 セッションが 1 子プロセスで、目安は 1 GiB RAM / 1 CPU。bot の中核の書き直しになり、#31・#44・#46・ADR-0008 で決めた制御が CLI 側に移る
  - Managed Agents: 自前のコードが最も少ない。Claude Code そのものではなく、Discord のツールと guild 単位の作業領域をイベント経由に作り替える必要がある
  - ハーネスを 1 つのまま、全プロバイダーぶんを Claude 向けに書き換える: 非推奨にする側のリクエストも変わり、比べる相手の「旧」が残らない

## 影響
- 得られる効果:
  - Anthropic のターンが、Anthropic のモデルに合わせたプロンプト・ツール・会話表現で動く
  - 新旧を同じビルドで、環境変数だけを変えて比べられる
- 費用・運用の負荷・残る制約:
  - 当面、2 つのハーネスを持つ。`codex` 側は #67 の凍結の検査で守る
  - 切り替えと切り戻しのたびに、Anthropic のチャンネルの会話が 1 回最初からになる（履歴の扱いを上の案にした場合）
  - bot に依存が 1 つ増える（`@anthropic-ai/sdk`）
  - Anthropic の beta の機能に依存する箇所ができる。機能ごとに無効にできるようにする
  - Claude Code の更新への追従は、自分たちの作業になる
- セキュリティ・障害時の挙動:
  - guild / DM 分離、権限チェック、Docker サンドボックスの上限は、どちらのハーネスでも同じ実装（`ToolRegistry` とサンドボックス）を通す
  - 切り戻しは 3 段。VPS の `bot.env` で `codex` に戻して再起動する。revert の PR をマージして配信する。起動に失敗したときは relay が自動で戻す（ADR-0006、変更なし）
