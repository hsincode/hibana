# ADR-0012: 設定 API の DB を Neon から Supabase（東京）に移し、API の関数を東京に置く

- 状態: 採用（2026-10-21）。Supabase と Vercel の `hnd1` での動作は、まだ確かめていない
- 決定日: 2026-10-21。移行先を Supabase Free（東京）にすること、API の関数を `hnd1` に移すこと（決定に `hnd1` を含むかは PR で確かめる）、データを bot の snapshot から復元すること
- 判断の過程を残した Issue: #92（調査記録）、#93（判断記録）、#27（Vercel の Fluid の使用量の超過）
- 置き換える／置き換えられた ADR: なし

## 要求と決定
- プロダクトの特性と、満たす要求:
  - bot は 30 秒ごとに `/internal/snapshot` を呼び、API はそのたびに DB を 1 回読む（#27 で、SSE をやめてポーリングにした）。Neon の Free は、5 分間アクセスが無いときだけ休止し、月 100 CU 時間までしか動かない。このポーリングでは休止できず、月の途中（2026-10-17 ごろ）で枠を使い切り、API が HTTP 402 で止まった（#92）。同じ止まり方は以前にもあった（[production.md](../production.md)）
  - 費用は $0 のまま。Neon でなくてもよく、普通の Postgres を候補にする（2026-10-21）
- 採用する構成・方式:
  - DB は Supabase の Free プラン、東京リージョン。API からは Supavisor の transaction モード（ポート 6543）につなぐ
  - ドライバは `@neondatabase/serverless`（HTTP）をやめて、Bun に組み込みの `SQL`（TCP、接続プールつき）にする。詳細は [database.md](../database.md)
  - API の関数を `hnd1`（東京）に置く（`apps/api/vercel.json` の `regions`）。DB と bot（VPS）が東京にあり、1 リクエストで DB を何回も順に呼ぶため
  - データは、bot の snapshot から復元する（`scripts/import-bot-snapshot.ts`）。Neon は 402 で読み出せない
- 比較した代替案と、採用しなかった理由（#93）:
  - VPS に Postgres を立てる: メモリの空きが約 500 MB しかない。Vercel に固定 IP が無いので 5432 番ポートを公開することになる。バックアップの運用が要る。VPS が落ちると bot と DB が同時に止まる
  - Prisma Postgres Free: 操作回数で課金されるので、ポーリングだけで無料枠に近づく
  - Neon Launch（有料）: 常時起動の分が請求になる（約 $19/月の試算）
  - データは Neon の枠が戻るまで待つ、または Neon を一時的に有料にしてコピーする: 待つ間ダッシュボードが止まる、または費用がかかる

## 影響
- 得られる効果: 計算時間の枠が無いので、ポーリングで枠を使い切る止まり方が起きない。費用は $0
- 費用・運用の負荷・残る制約:
  - Supabase Free の DB 容量は 500 MB、転送量は月 5 GB。ログは、プロンプトと返答の全文を 30 日分持つ
  - Free のプロジェクトは、7 日間ほとんど使われないと一時停止する。bot のポーリングが続く限り、かからない見込み
  - 復元では、セッション、ChatGPT アカウントの接続、ログ、利用停止の理由が戻らない
- セキュリティ・障害時の挙動:
  - Supabase の Data API は、ダッシュボードで公開を止める。加えて、API が作るテーブルすべてで RLS を有効にして、公開鍵からは行が見えないようにする（#93）
  - 手元以外のホストへは、`sslmode` で TLS を指定しないと起動しない。`require` は証明書を検証しない
  - 休止中に閉じられた接続は、プールを作り直して最大 3 回まで実行する。送信後に切れた書き込みは、重複しうる

## 見直す条件
- DB 容量が 400 MB を超えたら、ログの保持期間を短くするか、Supabase Pro（$25/月）にするかを決め直す
- Supabase の Free の条件（容量、一時停止、プロジェクト数）が変わったとき
- 送信後の切断による書き込みの重複が、実際に観測されたとき
